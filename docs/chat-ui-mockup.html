UMG 빌드 키 — 무엇을 어떻게

WBP_NPCChat의 각 위젯에 아래 값을 적용하면 이 시안에 가까워집니다.

색 팔레트
양피지 #E9DCC2 금테 #C6A24C 잉크 #3A2C1B 가죽(플레이어) #58452A 엠버(강조) #CF6F2A
폰트
이름·직업·버튼 = 명조/세리프(예: 나눔명조, Batang). 대사 본문 = 가독 산세리프(맑은 고딕/Pretendard).
외곽 프레임
Border 위젯 중첩 또는 9-slice 이미지로 금색 이중 테두리. 모서리 장식은 Image 위젯 4개로 코너에 배치.
헤더
좌측 문장(Crest) = Border+Text(이니셜) 또는 초상화 Image. 우측 상단 닫기 = Button("✕"). 하단에 금색 구분선(Image/Border).
메시지 말풍선
각 줄을 별도 위젯(WBP_NPCChatMessage / WBP_PlayerChatMessage)으로. NPC=왼쪽 정렬·양피지+금테, 플레이어=오른쪽 정렬·가죽 톤. Border의 Corner Radius + Padding(10/14).
스크롤 영역
ScrollBox 안 VerticalBox, 항목 간 Spacing 14. 새 메시지 추가 후 ScrollToEnd.
입력 바
EditableTextBox(Hint "말을 걸어보세요…") + 전송 Button(금색 그라디언트). 상단 금색 구분선.
생각중 표시
OnWaitingForResponseChanged(true)일 때 "…생각 중" Text + 점 3개(간단히 Throbber로 대체 가능) 표시, 전송 Button Disable.
연출(선택)
대화창 열릴 때 Fade+살짝 위로 이동(Widget Animation). 말풍선 추가 시 Fade-in. 과하지 않게.
