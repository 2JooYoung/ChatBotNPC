언리얼 엔진 게임 안에서 여러 NPC와 한국어로 대화하는 시스템. 대화 생성(LLM)과 음성 합성(TTS)을 전부 로컬에서 구동 — 외부 API·인터넷 없이 동작한다.

Why

왜 이 프로젝트를 만들었나

게임 속 NPC는 대개 정해진 대사만 반복한다. “진짜 대화가 되는 NPC를 만들 수 있을까” — 그 질문에서 시작했다. 상용 AI API를 쓰면 쉽지만 비용·인터넷 의존·데이터 유출이 걸린다. 그래서 대화 생성과 음성 합성을 전부 로컬에서 돌려, 인터넷 없이도 작동하고 유저 데이터가 밖으로 나가지 않는 오프라인 대화 시스템을 목표로 했다. 동시에 언리얼(C++)과 AI(파이썬)를 실제 프로덕트처럼 통합하는 경험을 쌓고 싶었다.

Why Local

로컬 LLM이면 뭐가 좋은가

상용 API 대신 모델을 내 PC에서 직접 돌릴 때의 이점.

비용

호출당 요금 0원

NPC가 몇 번을 대화하든 API 과금이 없다. 레이트 리밋도 없다.

프라이버시

데이터가 밖으로 안 나감

대화 내용이 외부 서버로 전송되지 않는다. 전부 로컬에서 처리.

오프라인

인터넷 없이 동작

네트워크·외부 서비스 장애나 정책 변경에 흔들리지 않는다.

제어

완전한 커스터마이징

모델·프롬프트·온도·토큰을 직접 통제. 게임에 맞게 튜닝 가능.

배포

서버 운영비 없음

유저 PC에서 구동 → 게임을 배포해도 백엔드 서버 비용이 들지 않는다.

확장

기능을 내 마음대로

프록시에 TTS·STT·요약 같은 기능을 자유롭게 붙일 수 있다.

균형 있게 — 대신 유저 PC 성능(특히 GPU)이 필요하고, 최상위 상용 모델보다 품질은 낮으며, 초기 셋업이 있다. 이 프로젝트는 “오프라인·비용0·프라이버시”가 그 트레이드오프보다 가치 있다고 보고 로컬을 택했다.

How It Works

서버 동작 — 대화 한 번의 흐름

플레이어가 메시지를 보내면 두 서버가 순서대로 움직인다. 텍스트(대화)와 음성(TTS)은 별개의 요청이라, 대사는 먼저 뜨고 음성은 준비되는 대로 재생된다.

◆ 1단계 — 대화 생성 (텍스트)
1

플레이어 입력 → UE가 요청 조립

시스템 프롬프트(성격·지식·금지) + 최근 대화 기록 + 이번 메시지를 OpenAI 형식으로 묶어 전송.

UE (게임)→ POST /v1/chat/completions프록시 :8000
2

프록시가 LLM으로 중계

요청 본문을 변형 없이 그대로 llama-server로 전달(passthrough).

프록시 :8000→ 그대로 전달llama :8080
3

LLM이 대사 생성 → 화면 표시

llama-server가 토큰을 하나씩 생성(~37 tok/s). 응답이 프록시를 거쳐 UE로 돌아오면 대사가 즉시 대화창에 뜬다.

llama :8080→ 대사 텍스트UE 대화창
◆ 2단계 — 음성 합성 (TTS)
4

UE가 그 대사를 음성으로 요청

대사가 확정되면 텍스트 + NPC별 피치/속도를 프록시의 음성 엔드포인트로 보낸다.

UE→ POST /tts프록시 :8000
5

MeloTTS가 한국어 음성 합성

프록시가 MeloTTS로 대사를 한국어 음성으로 만들고, NPC별 음색으로 피치를 보정(포먼트 보존).

프록시 :8000→ MeloTTS + 피치보정WAV
6

WAV 반환 → NPC 위치에서 재생

UE가 받은 음성을 파싱해 NPC 위치에서 3D로 재생. 음성 실패는 조용히 무시 → 대화는 안 끊긴다.

프록시 :8000→ audio/wavUE 재생
Under the Hood

실제로 도는 파이프라인

대화 한 번에 두 엔진이 함께 움직인다. LLM 서버(:8080)가 대사를 토큰 단위로 생성하고, 파이썬 프록시(:8000)가 그 대사를 한국어 음성으로 합성한다. 아래는 대화 중 실시간 서버 로그.

Personalization

NPC마다 다른 성격 · 다른 목소리

각 NPC는 데이터 자산(DataAsset)으로 정의된다. 성격·지식·금지 주제뿐 아니라, 음성의 피치·속도까지 NPC별로 지정해 목소리를 구분한다.

성격 (LLM)

시스템 프롬프트에 성격·말투·아는 것/모르는 것·금지 주제를 담아, 같은 질문에도 NPC마다 다르게 답한다. 대화 기록은 NPC별로 독립 저장.

목소리 (TTS)

단일 화자 TTS를 포먼트 보존 피치 시프트로 변형해, 캐릭터별로 자연스럽게 다른 음색을 만든다. 음성 실패는 대화를 막지 않도록 격리.
